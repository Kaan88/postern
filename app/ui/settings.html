Postern

Watches your Inbox and calendar over JMAP push and opens your webmail only while you use it.

Mail server
The server that answers /.well-known/jmap.
Not signed in
Opens your browser to sign in on the server itself (OAuth). No password is stored here; only a renewable token, in the system keyring.
Viewer
Your hosted webmail. Sign in once in the window it opens, with "Remember me" ticked.
0 frees all its memory at once; a few minutes makes a quick reopen instant.
If your webmail sits behind Cloudflare Access, its login opens in your default browser (where your Google session, passkeys and password manager are) instead of in this window.
Sent by the mail server itself, so they arrive with the webmail closed. Needs calendar alarms enabled on the mail server.

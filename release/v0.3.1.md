Postern for Linux: a deb, an rpm, and an AppImage that updates itself. New on every platform: Cloudflare Access sign-in in your own browser, and Settings adds `https://` to addresses for you.

The Windows installers are **not code-signed** yet, so SmartScreen will warn you on first run. Every file has a `.sha256` next to it, and a GitHub build attestation that proves it was built by this repository's release workflow.

Postern is an independent project, not affiliated with or endorsed by the Bulwark project or Stalwart Labs.

### Since v0.2.1

- feat: Linux packages for x64 and ARM64. A left click on the tray icon opens the webmail and a right click the menu, as on Windows; clicking a notification opens the message or event; the sign-in token is kept in the Secret Service keyring (KWallet, GNOME Keyring)
- feat: the AppImage adds itself to your application menu on first start and updates itself. It looks for a new release daily, checks the download's signature, replaces its own file and offers "Restart to update" in the tray menu; it never restarts by itself. "Install updates automatically" in Settings turns it off, and "Check for updates" in the tray menu works either way
- feat: "Sign in to Cloudflare Access in my browser" in Settings (off by default). With Cloudflare Access in front of the webmail, the login then happens in your normal browser, where your Google session, passkeys and password manager are, and the session is handed to the window, the way `cloudflared access login` does it. Other gateways have no such hand-off, so their login stays inside the window. Not yet tried on Windows
- change: an address typed without `https://` in Settings gets it added, and a missing or malformed address is explained on the page (the browser's own warning bubble came up empty on Linux)
- fix (Linux, since the withdrawn 0.3.0): a left click on the tray icon opened the menu instead of the webmail, and windows had no icon on Wayland
- fix (Linux): closing a window ends its browser process. A network process of about 70 MB stays until Postern quits

Linux is new and tested on KDE Plasma (Wayland) only. Not yet tried there: GNOME (which needs the AppIndicator extension to show tray icons), X11, and "Start at login", which fails if the AppImage's path contains spaces. Details are in the [technical notes](../../blob/main/app/README.md).

Most people want **Windows, AMD64**. On Linux, put the AppImage somewhere permanent (for example `~/Applications`), make it executable and start it.

The `.sha256` files are for checking downloads:

```powershell
(Get-FileHash .\Postern-Setup-0.3.1-x64.exe -Algorithm SHA256).Hash
```

```bash
sha256sum -c Postern-0.3.1-x64.AppImage.sha256
```

**Requirements:** Windows 10 1809 or later with WebView2 (built into Windows 11), or Linux with WebKitGTK 4.1, a tray that shows AppIndicator icons and a Secret Service keyring; a Stalwart server with OAuth and, for reminders, calendar alarms turned on; a hosted Bulwark Mail.

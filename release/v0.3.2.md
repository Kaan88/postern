A fix for Linux: the webmail window could go blank on every load.

The Windows installers are **not code-signed** yet, so SmartScreen will warn you on first run. Every file has a `.sha256` next to it, and a GitHub build attestation that proves it was built by this repository's release workflow.

Postern is an independent project, not affiliated with or endorsed by the Bulwark project or Stalwart Labs.

### Since v0.3.1

- fix (Linux): with a server-managed plugin of 64 KB or more installed in the webmail, the window went blank on every load. The webmail checks each such plugin's Ed25519 signature, and the Linux browser engine (WebKitGTK) fails on long messages: wrong answers from a little under 64 KB, and at 64 KB a crash of the page with the crypto library the AppImage carries (the same one Ubuntu 22.04 has). Postern now refuses those long checks, so the webmail uses its own JavaScript verifier instead. Nothing changes on Windows

Linux is tested on KDE Plasma (Wayland) only. An AppImage from 0.3.0 or later updates itself.

Most people want **Windows, AMD64**. On Linux, put the AppImage somewhere permanent (for example `~/Applications`), make it executable and start it.

The `.sha256` files are for checking downloads:

```powershell
(Get-FileHash .\Postern-Setup-0.3.2-x64.exe -Algorithm SHA256).Hash
```

```bash
sha256sum -c Postern-0.3.2-x64.AppImage.sha256
```

**Requirements:** Windows 10 1809 or later with WebView2 (built into Windows 11), or Linux with WebKitGTK 4.1, a tray that shows AppIndicator icons and a Secret Service keyring; a Stalwart server with OAuth and, for reminders, calendar alarms turned on; a hosted Bulwark Mail.

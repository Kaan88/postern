Postern now plays Bulwark's notification sound itself, Settings has a new compact layout, and two causes of a blank webmail window on Linux are fixed.

The Windows installers are **not code-signed** yet, so SmartScreen will warn you on first run. Every file has a `.sha256` next to it, and a GitHub build attestation that proves it was built by this repository's release workflow.

Postern is an independent project, not affiliated with or endorsed by the Bulwark project or Stalwart Labs.

### Since v0.3.2

- feat: notification sound. With the webmail window closed, Postern plays the sound Bulwark would: the one chosen in Bulwark, silent when Bulwark's mail or calendar sound is switched off or Do Not Disturb is on. It learns this each time the webmail window is open. Settings can instead name a sound (Beep, Cheerful, Involved, Swift, Relax) or turn it off. With the window open, Bulwark plays its own sound and Postern stays quiet
- change: Settings is one compact list with switches, and shows the version
- fix (AppImage): when the webmail played a sound, the window went blank. The AppImage carried the browser engine without its audio plugins (GStreamer), and the engine aborts the page when it has nothing to play a sound file with. The plugins are now bundled; the deb requires them and the rpm recommends them
- fix (Linux): the guard against the browser engine's Ed25519 crash on long messages (0.3.2) now also covers frames inside the page, such as a plugin's

The four sound files are Bulwark's, copied unchanged. They are not covered by Postern's MIT licence; see `app/sounds/README.md`.

Linux is tested on KDE Plasma (Wayland) only; the sound has not been tried on Windows yet. An AppImage from 0.3.0 or later updates itself.

Bulwark's plugins start again when the webmail window is opened from the tray long after it was last closed, and a notification click opens a new message instead of "This message is no longer available".

The Windows installers are **not code-signed** yet, so SmartScreen will warn you on first run. Every file has a `.sha256` next to it, and a GitHub build attestation that proves it was built by this repository's release workflow.

Postern is an independent project, not affiliated with or endorsed by the Bulwark project or Stalwart Labs.

### Since v0.3.5

- fix: Bulwark's plugins and server themes stayed off in a webmail window opened more than an hour after the last one was closed, until Bulwark's Settings › Plugins page was opened. Bulwark asks for its plugin list as the page starts, before it has restored the sign-in, and didn't ask again. Postern now holds that refusal until the sign-in is restored, then asks once more
- fix: clicking a new-mail notification could open "This message is no longer available": the message had only just arrived, and Bulwark hadn't fetched it yet. The webmail now opens on the mail list, and the message is opened from the list once Bulwark shows it

An AppImage from 0.3.0 or later updates itself.

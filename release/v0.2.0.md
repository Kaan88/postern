The first public build of Postern, a light tray companion for Bulwark Mail on a Stalwart server. It keeps one push connection to your server, shows new mail and calendar and task reminders as Windows notifications, and opens your own Bulwark in a window only while you use it.

The Windows installers are **not code-signed** yet, so SmartScreen will warn you on first run. Every file has a `.sha256` next to it, and a GitHub build attestation that proves it was built by this repository's release workflow.

Postern is an independent project, not affiliated with or endorsed by the Bulwark project or Stalwart Labs.

### Why Postern instead of Bulwark Desktop

Bulwark Desktop is the full official client. Postern is for when you mostly want to know that something arrived:

- **About 7 MB in the background.** The browser engine (the system's WebView2) only runs while the Bulwark window is open. Closing the window ends all of its processes within about 2.5 s.
- **Reminders from your server.** Stalwart fires calendar and task alarms itself and Postern shows them, so they arrive with no Bulwark page open. In testing they arrived within a second of their time.
- **No stored passwords.** You sign in with OAuth in your normal browser, so passkeys and your password manager work there. Postern keeps only a renewable token in Windows Credential Manager, and signing out asks the server to revoke it.
- **Browser sign-in for Bulwark too.** Inside Postern, Bulwark's login page offers "Sign in with your browser", using Bulwark's own hand-off. With Bulwark set to OAuth-only and Auto SSO, that goes straight to Stalwart's passkey prompt.
- **A 2.4 MB installer** that installs for your user without admin rights.

Before release, the code was audited by **Fable** (Anthropic's Claude Fable 5.2) in two passes covering correctness, security, reliability and performance. The fixes are in this release.

### Since v0.1.0

- feat: OAuth 2.0 sign-in with PKCE and dynamic client registration; app passwords are no longer supported
- feat: "Sign in with your browser" for the Bulwark window, via Bulwark's desktop hand-off
- feat: renamed to Postern; settings and sign-in move over from 0.1.x automatically
- feat: NSIS (per user) and MSI (per machine) installers for x64 and ARM64
- fix: browser sign-in no longer hangs when the browser opens an idle spare connection
- fix: a renewed token is kept even if Windows Credential Manager refuses to save it
- fix: a token the server rejects is forgotten, so Settings offers Sign in again
- fix: signing out during a token renewal can no longer leave you signed in
- fix: wrong or stale sign-in replies are ignored instead of cancelling the sign-in
- feat: the Bulwark window remembers its size, position and maximised state
- feat: reminder times are converted to your time zone, and a moved instance of a recurring event shows its new time
- feat: a log file in `%LOCALAPPDATA%\app.postern\logs` (no addresses, names or subjects)
- fix: notifications show Postern's name and icon with either installer
- fix: renewing the access token no longer drops the push connection for a moment
- fix: mail is not toasted twice, or all at once, after a failed first connection
- security: OAuth endpoints and configured URLs must use https; the Bulwark window loads only Bulwark and its mail server, and opens other links in your browser
- security: settings page under a strict content security policy; release workflow actions pinned to commits
- fix: very short token lifetimes no longer cause a renewal loop

**Requirements:** Windows 10 1809 or later with WebView2 (built into Windows 11); a Stalwart server with OAuth and, for reminders, calendar alarms turned on; a hosted Bulwark Mail.

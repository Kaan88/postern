# Security policy

## Supported versions

Only the latest release (or the latest commit on `main`, if there are no
releases) gets security fixes.

## Reporting a vulnerability

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/Kaan88/postern/security/advisories/new),
not in a public issue.

Include the version or commit, what an attacker can do, and steps to
reproduce. Never include passwords, tokens or other secrets in a report.
